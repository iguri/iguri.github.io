一、这是一座什么站
--------------------------------------------------------------------------------
「故人笔记」是一个个人博客，作者甲拉古日，彝族，四川人，1997 年生。
站点建于 2017 年（最早一篇是 Hexo 的 Hello World），此后换过几轮域名与
三套建站程序（Hexo → WordPress → Hugo），现在落在 Hugo + PaperMod 上。
关于页的域名历程里列了 7 个域名，画了删除线的是已停用的；本站现用 grer.cn。

它不是一个技术专栏，也不是一个营销号。用作者自己在「关于」页里的说法：
"本站内容以原创、分享和记录为主……没有任何盈利行为和捐赠通道"。所以这里
什么都写：修 Nginx 的配置、看一场电影的观后感、夜跑时遇到的一只鸽子、
对某条法规废止的梳理。题材分散，但有一条共同线索——都是作者本人真碰过
的事，写法上偏向"把过程记下来"，而不是"把结论发出去"。

页面顶部那句标语可以当作全站提纲：「审阅自己 、 超越自己 、 取悦自己」。
三个词分别对应站里的三条内容主线：
  · 审阅（折腾笔记 / 灵感记录）——技术自省与踩坑记录，占全站最多篇幅；
  · 超越（生活 / 日常水文）——运动、骑行、游戏、情绪，写给自己的流水账；
  · 取悦（分享安利）——书、电影、软件、梗，觉得好就写一篇推荐。

一句话版本：一个写了九年的中文个人博客，技术记录与生活随笔各占一半，
文风平实、细节多、几乎没有广告。

二、进来先走这五步
--------------------------------------------------------------------------------
如果你只有五分钟，按这个顺序逛，体验最完整：

  1. 首页           https://grer.cn/
     头像 + 打字机动效标语 + 一排社交图标。首页不直接列文章，作用是"表明
     身份"，别在这里找内容。

  2. 文章列表       https://grer.cn/blog/
     全站入口。每页 12 篇，共 6 页（前 5 页满 12 篇，第 6 页只有 2 篇）。
     按发布时间倒序，第 1 页最新。

  3. 归档           https://grer.cn/archives/
     按 年 → 月 折叠的完整目录，是"这个站到底写了多少东西"最直观的一页。
     2020 年最密集（30 篇），2022 年次之（20 篇）；2023 年只有 1 篇，
     2025 年整年空档，2026 年 11 月才重新开始更新。

  4. 搜索           https://grer.cn/search/
     前端模糊搜索，用 Fuse.js v7 在 /index.json 上做匹配，索引字段是
     title / permalink / summary / content。输入至少 2 个字才触发（配置项
     minMatchCharLength = 2），阈值 0.4，所以是"差不多就行"的模糊匹配，
     不是精确检索——搜错一两个字也能命中。

  5. 关于           https://grer.cn/about/
     作者自述、域名变迁史、友链申请要求，以及全站唯一的联系方式。
     想看"人"而不是"文章"，直接来这里。

四、六个栏目，各看什么
--------------------------------------------------------------------------------
▍文章列表 /blog/
   全站主干，每条含标题、摘要、日期。摘要来源分两种：2026 年的三篇长文与
   少数旧文有作者手写的 summary 字段，其余由 Hugo 按 60 字自动截断——所以
   以代码块开头的文章（如「用前端语言历遍本地文件夹」），摘要会直接显示
   <!DOCTYPE html> 这样的代码片段，属正常现象，不是排版坏掉。
   62 篇里有 25 篇配了封面，列表页会显示缩略图（cover 字段有值才渲染），
   但正文页反而不显示封面（hiddenInSingle = true），这是主题的刻意取舍。

▍归档 /archives/
   按年月分组，每组右上角标着篇数。适合"我想知道 2020 年他都在折腾什么"
   这类回看需求。年份锚点可直接跳转：#2026 #2024 #2023 #2022 #2020 #2017。

▍标签 /tags/
   111 个标签，最重的几个是 Hugo(6)、Wordpress(6)、网站日记(5)、Valorant(3)、
   我的观影(3)。标签比分类细，找具体主题（比如"骑行""影子系统""萌国icp"）
   用标签最快。

▍分类 /categories/
   只有 7 个，是站点的骨架，也是本导览书第五章的分节依据：
     分享安利 18 篇 · 折腾笔记 16 篇 · 日常水文 11 篇
     生活 6 篇 · 灵感记录 5 篇 · AI仁有话说 3 篇 · 灵感分享 1 篇
   另有 2 篇没有分类（Hello World 与「独怜一雁飞南海」），在列表页照常出现，
   只是点进正文看不到分类链接。

▍相册 /photos/
   22 张图，来源是 static/photos 目录，直接扫描生成，不用手动维护。
   配图说明取文件名（所以有几张显示为 R-C (1)、JPEG 这类原始名）。
   页面顶部引《晋书·孙统传》"纵意游肆，名山胜川靡不穷究"。
   点图进全屏查看器，支持左右切换。

▍关于 /about/ 与 /links/
   /links/ 不独立成页，会 0 秒跳到 /about/#友链，做跳转是为了保留 canonical、
   避免重复内容。友链共 4 个站点（唯爱忆、木木木木木、失眠海峡、兮族网），
   页面里同时给了本站的 Iconfile 与 logotype 地址，方便互换。

五、内容分卷：七类文章各是什么
--------------------------------------------------------------------------------
按分类把 62 篇按性质归堆，能快速判断"这个站的技术含量在哪"。

▍AI仁有话说（3 篇）——全站最硬的部分，2026 年新开的分卷
   三篇都是长文，单篇 200+ 行，带图表、代码与外部信源：
   · NVFP4 KV Cache 与推理内存墙（显存账怎么算、4bit 量化为什么省的是驻留能力）
   · NIKKE 启动器 CDN 投毒（供应链攻击全链路复盘 + 取证脚本）
   · Redis 承载 Agent 会话记忆（记忆层边界、压缩时机、并发写入）
   特点：先列反例/常见错误，再给可运行代码，最后给排查清单。不是资讯搬运。

▍折腾笔记（16 篇）——建站与运维的"施工日志"
   横跨 WordPress（评论 UA、阅读数、顶部管理条、5.4 注册跳转）、
   Hugo（相册页、新标签打开、随机文章、首行缩进、PaperMod 改造）、
   服务器（Nginx HTTP→HTTPS、宝塔 webhook 自动同步、计划任务推 sitemap、
   GitHub Actions 部署）、安卓（X-plore 局域网映射、MT 管理器内购）。
   写法统一：问题现象 → 试过什么 → 最后用的方案 → 代码。旧文里的方案多已
   过时（WordPress 那批针对 5.x），但排查思路仍可读。

▍分享安利（18 篇）——书 / 影 / 漫 / 软件 / 域名
   数量最多的分类，也是口味最杂的：
   · 影视：《夏洛特烦恼》《首尔之春》《花束般的恋爱》《在你们离开以前》
   · 国漫与游戏：《孙悟空之噬天魔猴》《黑神话：悟空》
   · 软件：PicGo、Algodoo、Shadow Defender、PHPCUSTOM、X-plore
   · 数码与政策：小米关闭广告、QC5 快充、.cc 域名备案、收容教育废止
   共同点：都不是评测，而是"我用过 / 我看过，所以记一笔"。

▍日常水文（11 篇）——网络热点与即时感慨
   黑人抬棺、舔狗日记、窃·格瓦拉出狱、三伏天、高考、哀悼日、QC5 快充。
   时效性最强，也最容易过时，适合当"2020 年前后的中文互联网切片"来看。

▍生活（6 篇）——身体与情绪的记录
   骑行（天府绿道百公里、龙泉驿路线）、夜跑、工作焦虑、无所事事的日子。
   是理解作者本人最快的一卷，几乎每篇都配了现场照片。

▍灵感记录 / 灵感分享（6 篇）——半技术半随笔
   CSS Grid 布局讲解、前端遍历本地图片、GRTask 自动化托管文档、
   凌晨三点的失眠、酷我内购实录等。

▍没有分类（2 篇）
   Hello World（2017-03-03，Hexo 默认模板，站点的起点，留着没删）与
   独怜一雁飞南海（2022-06-27，frontmatter 里分类字段被整行注释掉，
   所以正文页没有分类标签，只能靠归档和日期找到它）。

▍如果只挑五篇读
   站里 62 篇分量并不均等。按"信息密度 + 可复用性"挑，这五篇最值：

   1. 用 Redis 承载 Agent 会话记忆：存储边界、压缩时机与并发写入
      https://grer.cn/blog/redis-agent-session-memory.html/
      把会话消息、会话元信息、跨会话画像三类状态拆开，给出 Store 的封装
      粒度、摘要压缩的时机与 per-session 并发写入的取舍。踩过 WRONGTYPE
      或 message._getType is not a function 的人，看这篇最省时间。

   2. NIKKE 启动器 CDN 投毒：一次只改四个 JS 文件就落地的远控链
      https://grer.cn/blog/nikke-launcher-cdn-supply-chain.html/
      完整攻击链复盘，拆掉"官方域名即可信""改了文件会被发现""源站修好就
      安全"这三个默认假设，附资产哈希校验与离线取证脚本。不玩这游戏也值得
      读，因为它讲的是发布链路上缺一次校验要付多少代价。

   3. HBM 只增 3%，吞吐却涨 30 倍：NVFP4 KV Cache 与 AI 推理的内存墙
      https://grer.cn/blog/nvfp4-kv-cache-memory-wall.html/
      把推理显存账算清楚：模型权重是常数，KV 才是变量；4bit 量化省下的
      不是数字而是驻留能力，而驻留能力只有转成 cache hit rate 才值钱。

   4. 解锁成就 共享单车骑行天府绿道百公里
      https://grer.cn/blog/220605.html/
      全站最有生活气的一篇：六点起床、共享单车、天府绿道刷完百公里，配
      沿途照片，是"生活"这一卷的样板。

   5. 深入理解前端中的 CSS Grid 布局
      https://grer.cn/blog/css-grid.html/
      站里唯一一篇体系化的前端教程，从网格容器、轨道、网格线讲到实际布局。

七、链接规范与已知边界
--------------------------------------------------------------------------------
1) 正文 URL 必须带结尾斜杠
   https://grer.cn/blog/220605.html/   ✔ 200
   https://grer.cn/blog/220605.html    ✘ 301 跳转
   本文件里所有文章链接都已按带斜杠的规范写好，复制即可。
   （例外：/photos/ 下的图片、/resume/resume.pdf、/index.json 等静态资源
     是直接文件路径，不带斜杠。）

2) 分类 slug 大小写敏感
   /categories/ai仁有话说/  ✔ 200（开头是小写 ai）
   /categories/AI仁有话说/  ✘ 404
   其余 6 个分类都是中文，直接写未编码的中文即可访问。

3) 分页只有 1–6 页
   /blog/page/7/ 是 404，不是空页。翻到底就是第 6 页。

4) /links/ 会跳转
   访问 /links/ 会立刻跳到 /about/#友链。做外链时建议直接写
   https://grer.cn/about/#友链，少一跳。

5) 旧地址仍可用
   每篇文章都配了 aliases（如 /blog/2020/33ef.html/index.html），
   60 条旧链接全部实测 200，站外老链接不会断。

6) 本站没有的功能
   没有评论登录体系之外的账号，没有广告位，没有捐赠通道，没有站内私信。
   评论由 Twikoo 承载（comments.grer.cn），不需要注册即可留言。

7) 与你可能有关的两处"过期内容"
   · WordPress 系列（2020 年 4 月）针对 WP 5.4，现在的 WP 版本已不适用；
   · PaperMod / Hugo 相关配置写于 2022–2024 年，主题已多次大版本更新，
     照抄前先对照当前主题文档。
   作者本人在「折腾主题PaperMod」里也承认过这点（"时隔一年……主题都迭代了
   好几个版本"）。
